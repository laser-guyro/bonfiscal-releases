# BonFiscal – versiuni

Kiturile de instalare BonFiscal (Okavango → Tremol M20) și `manifest.json`, din care calculatoarele din centre își iau actualizările.

- Kiturile sunt la [Releases](https://github.com/laser-guyro/bonfiscal-releases/releases).
- `manifest.json` spune ce versiune primește fiecare canal: `pilot` și `stable`.
- `manifest.json.sig` este semnătura lui. BonFiscal instalează doar versiuni cu semnătură validă și cu amprenta SHA-256 corectă.

Codul sursă nu este public.
